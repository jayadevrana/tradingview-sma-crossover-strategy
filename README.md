# TradingView SMA Crossover Strategy

A clean TradingView Pine Script strategy example developed by Jayadev Rana for traders who want to understand Pine Script strategy entries, SMA crossover logic, visual buy/sell markers, and TradingView Strategy Tester basics.

## Overview

This project demonstrates a simple fast SMA and slow SMA crossover strategy. When the fast SMA crosses above the slow SMA, the script opens a long position. When the fast SMA crosses below the slow SMA, the script opens a short position.

The goal is educational: the code is intentionally small, readable, and easy to modify. It can help traders understand how a Pine Script strategy developer structures entries, plots, and Strategy Tester logic. For custom TradingView strategy development, visit https://jayadevrana.com.

## Features

* Fast and slow SMA crossover logic
* Long entry on bullish crossover
* Short entry on bearish crossover
* Buy and sell markers on chart
* Strategy Tester support
* Clean Pine Script v6 formatting
* Easy inputs for SMA lengths

## How to Use in TradingView

1. Open TradingView.
2. Go to the Pine Editor.
3. Copy the code from `sma_crossover_strategy.txt`.
4. Paste it into the Pine Editor.
5. Save the script.
6. Add it to your chart.
7. Open Strategy Tester to review historical behavior.
8. Adjust the fast and slow SMA inputs for research.
